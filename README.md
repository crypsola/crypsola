# crypsola — Bug Bounty Hunter

Independent security researcher hunting smart-contract bugs in DeFi and pre-mainnet protocols. I read code, prove faults locally, and report once — with evidence.

## Focus
- Lending & perps protocols — margin, liquidation, and accounting invariants
- Oracle & pricing faults, rounding and unit mismatches
- Access control, cross-market composition, hostile-token edge cases

## Method
- Local, reproducible Foundry PoC before any report — no speculation, no scanner dumps
- One report per fault, with measured impact and a concrete remediation
- Responsible disclosure only, through each program's official channel
- Write-ups are published only after the program clears disclosure or the case is closed

## Tooling
Foundry · Slither · cast

## Field notes
Every engagement is backed up in its own repository on this account — opened to the public once the team has claimed the finding or the reward has settled.
